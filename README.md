# 燃費ログ（fuel-log）

満タン法の燃費を給油のたびに記録し、推移をグラフで見る個人用PWA。データは端末内だけに保存し、外部には一切送信しません。オフラインで動きます。

公開先: https://akihirokunii.github.io/fuel-log/

公開・検証の現在地は [受け入れ確認](docs/ACCEPTANCE.md) を参照してください。

## iPhone のホーム画面に追加する

1. iPhone の Chrome で上記公開URL を開く
2. 共有ボタンをタップ → 「ホーム画面に追加」を選択
3. ホーム画面の「燃費」から開き、画面下部の「オフラインで使えます」を確認する。その後は通信がなくても記録できる

ホーム画面に追加したアプリは、Chrome のタブとは別の保存領域を使います。記録は必ずホーム画面のアイコンから開いたアプリで行ってください（先にタブで記録した分は、タブ側でバックアップを書き出し、アプリ側で復元すれば移せます）。

## 使い方（満タン法の運用）

初めて使う場合、まず車を満タンにしてトリップメーターをリセットします。その給油は開始基準とし、次の給油から記録してください。すでに前回の満タン給油時にリセット済みなら、今回の給油から記録できます。


- 満タン給油のたびにトリップメーターの値（前回リセットからの距離）・給油量・金額（任意）を記録し、トリップメーターをリセットする
- 満タンにしなかったときも、その時点のトリップ距離を入力して「詳細 → 満タンにしなかった」にチェックし、トリップメーターはリセットする（燃費は次の満タン給油のときに合算して計算される）
- オドメーター（総走行距離）は記録しない

## 画面

- **記録**: 日付・走行距離・給油量・金額を入力。保存時に燃費と前回との差を表示
- **グラフ**: 1か月・半年・1年・全期間の切り替え。燃費の折れ線と平均線、統計（平均・最高・最低・件数）、コスト（円/L・円/km）
- **一覧**: 全記録を新しい順に表示し、タップで編集・削除。最下部の「データ管理」に CSV 書き出し・取込、JSON バックアップ書き出し・復元、全削除

## データのバックアップ

データはこの端末のブラウザ内（IndexedDB）だけにあります。機種変更やブラウザのデータ消去の前に、一覧タブの最下部「データ管理」からバックアップを書き出してください。CSV の取込は現在の記録への追記、バックアップからの復元は全データの置換です。

## アプリの更新

「新しい版に更新」が出たら、入力中の記録を先に保存してから押してください。更新は確認後に行われ、保存済みの記録は残ります。

## 開発

```bash
npm ci
npm run dev           # http://localhost:5173/fuel-log/
npm test              # 単体テスト
npm run build         # ビルド
npm run icons         # PWAアイコン生成
```

技術スタック: React 19 + TypeScript + Vite / Dexie / Recharts / vite-plugin-pwa

設計規約は [CLAUDE.md](CLAUDE.md)、仕様は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) を参照してください。

## デプロイ

main へ push すると GitHub Actions が自動的にテスト・ビルド・デプロイします。初回だけリポジトリの Settings → Pages → Source を「GitHub Actions」に変更してください。
